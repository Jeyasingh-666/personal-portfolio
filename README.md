# Jeyasingh T. — Portfolio Website

A responsive portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — theme, layout, responsiveness, and animations
- `script.js` — typing effect, mobile menu, reveal animations, and active navigation

## Run locally
Open `index.html` in your browser. An internet connection is needed for the Google Fonts used in the design; the website still works without them using fallback fonts.

## Publish with GitHub Pages
1. Create a public repository, for example `my-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Commit your changes.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Wait for the Pages deployment to finish and open the website link shown in Settings → Pages.
